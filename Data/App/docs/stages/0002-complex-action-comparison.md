# 第2阶段 卡气候选与共同空间量化

日期 2026年10月10日。此阶段在阶段1八路完整输入上实现候选分段与 A/B 量化，正常运行不依赖 Node 或键盘 SDK。

当前范围已收紧：卡气入口仅开放身份已确认的月牙湾，并要求分别填写开头练习区域。其他地图仍可查看输入与普通分析。下文保留阶段2当时的实现和验收记录，最终范围及浏览器验收见[第4阶段](0004-acceptance-and-moon-bay-scope.md)。

## 改动与实现

新增定义式模块 `NativeComplexActions.ps1`、`NativeComplexComparison.ps1` 和前端接口模块。候选以合并前进释放区间为单位，需要观察到漂移输入和单方向输入；持续漂移输入单独标为待核对候选。相似输入也可能是普通漂移，不把候选名称当成游戏原生动作，不强制四段，不按成功或失败评分。

相邻候选只有同一有效轨迹块、回前已观察到、其间输入已知且间隔不超过公开的1.5秒分组阈值时才组成候选链。这个阈值用于分组，不是游戏机制。未知、数据时间空洞、位置断点会阻断连接。每份录像自己的结束保留；输入恢复前进、原生漂移结束是独立字段。

复用 NTA 单调空间内核，时间不参与匹配代价；规范化 A/B 顺序后计算，确保互换时共同区间与时间差方向稳定。候选阶段采用互相唯一的空间邻近配对；缺失或歧义不按序号硬配。两侧姿态块变化额外断开共同空间分量。

同一共同空间区间计算 A−B 用时。参考起点映射到 A 轨迹后，A 实际起点时间减去 A 经过该位置的时间，得到起卡位置的等效秒数；录像之前的累计落后不混入。自然动作持续时间、自己的速度指标另行保存。重叠的共同窗口不能逐行相加。

页面增加“卡气量化与参考分析”，沿用当前 A/B 选择，可填各自录像时间筛选关注候选。筛选保留自然终点，量化由按钮触发；播放与地图拖动不会重复分段或空间计算。点击定位 A 跳转已有采样指法面板；A/B 输入证据保留 CSV 原索引、实际时间与八路原值。测量结果可导出 JSON。

## 记录的数据

- 原始候选边界、来源 CSV 索引、链号、实际候选数量、边界是否完整。
- 前进完全释放采样数、漂移脉冲、方向保持、回前停留、下一段衔接。
- 按实际时间戳计算保持时长下界；仅两侧释放均有观测时发布上界。未知边界不补零。
- 入段、自然末、峰值、最低与时间加权平均速度；推进效果激活采样数或未知。
- 原生漂移结束与正负180度完整夹角。夹角使用相邻有效位置位移与原生车头朝向，属于运动方向估算，不冒充直接速度向量角，也不覆盖原来的 slip 字段。
- 共同区间用时、自然持续差、峰值差、起点进度差、参考起点在 A 上的位置和等效时间。
- 采样与控制点跨度、局部空间分离组成的分辨率估计。它是解释精度的估计，不能当作严格误差保证。

## 验证与边界

Windows PowerShell 5.1 合成回归已通过，覆盖原生边界、按住时长上下界、62/67合并、非二元输入、同时间记录、数据断点、开放边界、自然出口、A/B互换、缺失卡段及起点前存在累计5秒延迟。原有空间内核不作修改。

实际 HTTP 路由、完整 CSV 读取、路径保护继承、区域不截断自然末、缓存复用和失效已验证。前端实际控制器的旧请求取消、筛选、定位、证据展开和速度 SVG 通过 Node DOM 行为测试；这不等价于真实浏览器视觉验收。

当前可访问的一份支持格式真实录像，5049条输入全部进入分析，产生5个待核对候选、4条候选链、4726条可计算夹角记录；单次分段约3.7秒。它不属于已经核对的月牙湾职业四连卡金标，不能据此声称这5段均为卡气。诊断结果只在本地忽略目录 `Data/Diagnostics/Stage2` 保存。

未支持的222字节格式、漏采样短按、物理键名与RT毫米数仍不可恢复。高级技巧名称需要游戏回放核对。职业时机建议与参考分布在第3阶段交付；阶段闭合门禁结果见第3阶段报告。
